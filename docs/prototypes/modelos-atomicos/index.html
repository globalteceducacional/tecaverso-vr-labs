Como usar em VR

  1. Selecione uma vitrine na parede; caminhe até a ala oposta para ver as partículas. No navegador, use “Virar”.
  2. Use +/− no console para montar o átomo.
  3. Segure e gire o modelo no lugar. No navegador, arraste com mouse ou toque; “Recentralizar” restaura a vista.
  4. Compare Camadas e Nuvem; a composição permanece.

Limpar montagem?

As contagens voltam a zero.

Protótipo: clique/toque simula controle 3D; arrastar simula girar o átomo fixo. “Virar” simula caminhar até a parede oposta.
